# HomeSphere Runtime Services

Planned implementations:

- homehub — central event/state coordinator
- cctv — simulated camera portal and event source
- ir — predefined IR command simulator
- lock — smart-lock state simulator
- hvac — thermostat/telemetry simulator
- lighting — lighting scene simulator
- energy — energy telemetry simulator

Keep device simulators small and deterministic. Avoid generic command-execution interfaces.
