# HomeSphere Android Application

The Android app is a fictional HomeSphere beta application used as a reverse-engineering artifact.

Planned functions:

- Home/device dashboard
- Camera viewer
- Device status
- Developer/debug configuration artifact
- Synthetic session/device metadata

Use a modern Android SDK with minimal dependencies.

All endpoints, IDs, tokens, and credentials must be synthetic and valid only inside the HomeSphere challenge environment. Never embed real API keys.
